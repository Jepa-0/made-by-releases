# Made By... playtest

Download **MadeBy-Windows.zip** from the [latest release](https://github.com/Jepa-0/made-by-releases/releases/latest). Extract the whole ZIP into a folder you own and open **MadeBy.exe**. Windows 10/11, 64-bit.

Type what you want to play in the chat; the world forms out of dark liquid. Solo play works offline. Playing together with friends needs Steam running and signed in, with a separate Steam account per player; this early prototype uses Steam's Spacewar test app ID 480.

Each player's settings, worlds and records stay on their own computer and survive updates.

This repository contains playtest downloads only. Source code is maintained privately.
